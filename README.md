# Freelancer Migbreu

Landing page para un diseñador y desarrollador web freelancer. Proyecto de portafolio construido con HTML5 y CSS3, con diseño responsive y secciones de servicios y contacto.

## Características

- Estructura semántica en HTML5.
- Estilos personalizados con variables CSS.
- Diseño responsive con media queries, Flexbox y Grid.
- Sección hero con imagen de fondo y llamada a la acción.
- Tarjetas de servicios: diseño web, aplicaciones web y e-commerce.
- Formulario de contacto.

## Tecnologías

- HTML5
- CSS3
- Google Fonts (Krub)

## Estructura del proyecto

```
.
├── index.html
├── css/
│   ├── normalize.css
│   └── styles.css
└── imagenes/
    └── hero.jpg
```

## Ejecutar en local

Abre `index.html` directamente en el navegador o inicia un servidor local:

```bash
python -m http.server 8000
```

Luego visita `http://localhost:8000`.
